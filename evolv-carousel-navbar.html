Sobre o Projeto

O Evolv é o Projeto Final de Curso (PFC) desenvolvido com o objetivo de apresentar uma solução prática, unindo os conhecimentos adquiridos ao longo do curso em um projeto real e funcional.

Objetivos

Aprendizado

Aplicar na prática os conceitos estudados durante o curso.

Inovação

Propor uma solução com identidade própria para um problema real.

Entrega

Apresentar um projeto completo, funcional e bem documentado.
